MLIR · LLVM · hardware-aware compilation

nano-dsp-mlir

A small MLIR compiler for a tiny DSP dialect. It tiles and vectorizes each op for a specific machine, using that machine's cache size and SIMD registers, then proves the result didn't change by a single bit.
